# Security Policy

## Reporting Security Issues

**NEURON TS LABS** and **Mohd Tahir Shaikh** take the security of SoundForge Studio seriously.

If you believe you have found a security vulnerability in this project, please **do not** open a public issue. Instead, report it privately via email:

* **Contact:** `tahirshaikh744@gmail.com`
* **Subject:** `[SECURITY] Vulnerability in SoundForge Studio`

Please include:
1. A description of the issue and its potential impact.
2. Steps or proof-of-concept to reproduce the vulnerability.
3. Your name / GitHub handle if you wish to be credited for the discovery.

We will acknowledge receipt within 48 hours and work with you to patch the issue before any public release.
